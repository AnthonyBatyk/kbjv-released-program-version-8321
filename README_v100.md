# КБЖВ — тестова версія v100

Базова версія: v99. Репозиторій GitHub Pages: `kbjv-released-program-version-8321`. Головну робочу версію не змінено. Cloudflare Worker / D1 залишаються v91, правки Worker не потрібні.

## Зміни

1. Архів. Одне поле пошуку шукає за датами у форматах `YYYY-MM-DD`, `DD.MM.YYYY`, `DD.MM.YY`, текстом підсумку, окремими макропоказниками, коментарями, складом і типом дня. Додано англійські синоніми для `cheat meal`, `training`, `rest`; пошук і за кількома словами, без окремих фільтрів. Самі записи й синхронізація не змінюються.
2. Конвертер. Кнопка `Показати інструкцію` / `Сховати інструкцію`; описані швидкі напрямки, вибір з 20 категорій і пошук одиниць, спосіб введення і копіювання. Каталог конвертера не змінено.
3. Порівняння цін товарів. Замість вкладених сірих карток — одна загальна картка з роздільними лініями. Поля мають видимі межі навіть без фокусу.
4. Калькулятор дат. Та сама структура: один блок із лініями, менші відстані між датою/часом, обмеження ширини нативних input date/time для вузьких екранів.
5. **Новий блок між конвертером і порівнянням цін** — перерахунок КБЖВ сирого продукту на готовий. Вхід: маса сирого та готового (без ваги посуду); поживність 100 г сирого (калорії, білки, жири, вуглеводи, цукри, сіль, клітковина; дані можна залишити невідомими); за бажанням вага готової порції і/або ціль калорійності. Результат: показники на 100 г готового, показники порції, потрібна маса готового під ціль; копіювання. Зберігається тільки факт успішного копіювання в консолі — не персональні/продуктові значення. Поля очищуються при виході зі «Зручностей».

### Формули

Калорійність (чи інша поживність) готового продукту на 100 г = поживність сирого на 100 г × маса сирого продукту / маса готового продукту.

Для порції M готового продукту: поживність порції = поживність готового на 100 г × M / 100.

Маса готової порції для бажаної калорійності K = K × 100 / калорійність готового на 100 г.

Формули припускають, що загальна поживність партії залишилася незмінною: додані олії/соуси, зливання рідини, втрати поживних речовин потребують окремого обліку.

## Встановлення

Замінити у **тестовому** репозиторії п'ять файлів: `index.html`, `style.css`, `script.js`, `utilities.js`, `sw.js`. Іконки та `manifest.webmanifest` залишилися без змін. Версія сайту у консолі `v100`, Worker `v91` за умови, що саме це повертає поточний Worker. Перед установкою зробити експорт даних.

## Перевірено

- `node --check` JavaScript-файлів.
- Пошук `cheat meal`, `cheatmeal`, `чітміл`, `читміл`, `training`, `rest`, дата у кількох форматах, склад і коментар, змішаний пошук за кількома словами.
- Локальний Chromium із тестовим DOM на ширинах 320 / 390 / 768 / 1280 px: відсутність горизонтального переповнення, нові поля дати й часу не виходять за межі, інструкція відкривається і закривається.
- Перерахунок: 100 г сирого з 340 ккал/100 г -> 250 г готового: 136 ккал/100 г; порція 125 г -> 170 ккал; ціль 170 ккал -> 125 г. Інший приклад, перевірка некоректних чисел, очистка при виході, копіювання та подія аудиту.

Не проводилося тестування з реальним Worker/D1 або на фізичному iPhone; після розгортання потрібна перевірка реального PWA й Safari.

# КБЖВ — тестова версія v101

Базова версія: v100. GitHub Pages: kbjv-released-program-version-8321. Cloudflare Worker залишається v91 (без змін).

## Зміни
- «Зручності»: кнопка «Знайти інструмент» відкриває фіксоване вікно зі списком із 7 інструментів. Натискання переводить до відповідного блоку.
- «Показати інструкцію» → зелений стан, «Сховати інструкцію» → червоний стан з правильним динамічним підписом.
- Оформлення: прибрано постійні контури полів перерахунку КБЖВ, порівняння цін і дат; залишено помітний контур фокуса. Ущільнено форму дат і обмежено ширину елементів.
- «Перерахунок КБЖВ»: додано вибір продукту з актуальних КБЖВ Блоків у фіксованому вікні з пошуком. Поля з невідомими показниками залишаються порожніми. Значення на 100 мл не підміняються значеннями на 100 г.
- Підписи маси й порції тепер використовують (г) і (ккал).
- Введені значення інших інструментів зберігаються **локально для кожного акаунта на цьому пристрої** та переживають вихід з розділу й перезавантаження сторінки. Це **не** експорт, не хмарна синхронізація, не імпорт і не історія розрахунків.
- Згенерований пароль, його налаштування й вміст поля генератора **не записуються** до чернетки; генератор очищується при виході, перезавантаженні та поверненні з BFCache.

## Реліз
У тестовому репозиторії GitHub замінити тільки: `index.html`, `style.css`, `script.js`, `utilities.js`, `sw.js`. Інші файли без змін. Cloudflare Worker/D1 без змін.

## Тести
- Синтаксис JavaScript перевірено через `node --check`.
- Локальні ізольовані Chromium DOM-тести: 320, 390, 768, 1280 px. Без горизонтального переповнення; поля дати не виходять за межі контейнерів.
- Вибір інструмента; інструкція (зелений/червоний стан), пошук продукту та заповнення КБЖВ, перерахунок 340 ккал/100 г з 100 г сировини у 250 г готового = 136 ккал/100 г; локальне збереження й відновлення стану, перевірка відсутності пароля в чернетці.
- Повний живий Cloudflare + iPhone тест не проводився. Браузерний тест використовував ізольовану копію DOM та симульовані продукти; інтеграцію з авторизованою D1 слід перевірити після публікації.

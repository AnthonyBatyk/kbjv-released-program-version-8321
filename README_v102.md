# КБЖВ — тестова версія v102

Основа: v101. GitHub Pages: kbjv-released-program-version-8321. Worker v91, D1 та ключі — БЕЗ ЗМІН.

## Виправлення вкладки «Зручності»

- Уніфіковано звичайну жирність кнопок (400, 14 px): такий самий базовий шрифт, як у кнопок основного сайту. Навігаційні вкладки залишаються у своєму стандартному стилі.
- «Знайти інструмент» перейменовано на «Знайти зручність», розтягнуто на всю ширину. У вікні вибору заголовок «Виберіть зручність:».
- У калькуляторі дат нативні поля вибору дати/часу залишено функціональними, але візуально замінено компактними керувальними елементами з датою `ДД.ММ.РРРР` або часом та піктограмою. Тепер текст не обрізається праворуч. Записані раніше значення відновлюються.
- «Перерахунок КБЖВ»: пошук продукту має підпис «Пошук за назвою:» та підказку «Пошук продукту...». Реакція кнопок вибору/закриття — зелена/червона, тимчасова; на підтвердженні обраного продукту зберігається зелена реакція.
- «Показати/Сховати інструкцію» тепер повертається до основного синього кольору після ~1,45 с, при цьому інструкція залишається відкритою/закритою до наступного натискання.
- Версію сайту піднято до `v102` у коді, HTML і PWA-кеші; URLs ресурсів оновлено для обходу старого кешу.

## Що не змінювали

Профіль, КБЖВ Блоки, Калькулятор, Архів, логіка спільної Консолі, структура JSON-експорту й імпорту та формули розрахунків — без функціональних змін. Локальна чернетка зручностей зберігає попередній ключ `_v101`, аби користувачі не втратили введені значення при переході на v102. Згенеровані паролі не зберігаються у чернетці.

## Файли для оновлення

Замінити у ТЕСТОВОМУ репозиторії GitHub: `index.html`, `style.css`, `script.js`, `utilities.js`, `sw.js`. Решту файлів залишити без змін. Cloudflare Worker не змінювати.

## Перевірки

`node --check` для трьох JS файлів, Chromium DOM-тести (320/390/768/1280 px): однакова жирність кнопок, повна ширина вибору зручності, відкриття та закриття модальних вікон, короткочасне підсвічування кнопок, пошук продуктів, вибір продукту, введення дат і часу, калькуляція різниці, відсутність горизонтального переповнення, відсутність пароля в локальній чернетці. Реальний iPhone і інтеграція з живою Cloudflare D1 не тестувалися.

# КБЖВ — тестова версія v103

Основа: v102. Репозиторій: `kbjv-released-program-version-8321`. Cloudflare Worker залишається v91, жодних змін D1 чи ключів.

## Зміни

- Додано великий заголовок «Корисні функції та розрахунки:» над описом вкладки «Зручності». Типографіка — як у заголовків КБЖВ Блоків та Калькулятора, з адаптивним розміром на телефоні.
- Кнопку «Знайти зручність» перейменовано на «Знайти потрібний блок» без зміни розташування, стилю та функцій пошуку.
- Номер версії оновлено до v103 у відображенні консолі, скрипті та PWA-кеші.

КБЖВ v104 — тестова версія (побудовано на v103)

ЗМІНИ
• В усіх 7 блоках «Зручностей» додано окрему кнопку «Очистити». Якщо нічого очищати — вона неактивна.
• Генератор паролів: очистити можна лише згенерований пароль, налаштування генерації залишаються; пароль не записується в резервну копію та локальну чернетку.
• Годинник: «Очистити» повертає часовий пояс пристрою.
• Коефіцієнт, конвертер, КБЖВ готового продукту, порівняння цін, калькулятор дат: окреме очищення без впливу на інші блоки.
• Короткочасне червоне підтвердження очищення, як для інших негативних дій.
• Додано запис про очищення блока в наявну консоль (без пароля чи введених ваг).
• Збереження чернетки «Зручностей» примусово виконується під час згортання або виходу; локальні чернетки ізольовані за акаунтом.
• Для вкладених модальних вікон піднімається саме останнє відкрите; нижнє стає неактивним, Escape закриває верхнє.
• Версія в консолі та кеші: v104. Worker не змінюється (v91).

ПЕРЕВІРКИ (ІЗОЛЬОВАНИЙ CHROMIUM, ІМІТАЦІЯ API)
• Синтаксис трьох JS-файлів, відсутність повторюваних HTML id.
• 320 / 390 / 768 / 1280 px: переходи вкладок, профіль, адмінка, дві консолі, нові очищення, арифметика, відсутність горизонтального переповнення та JS-помилок у перевірених сценаріях.
• Імітація мобільного перегляду: фокус на полях без зміни visualViewport.scale; дві модалки фіксують фон, Escape закриває лише верхню.
• Імітація перезавантаження: значення не-конфіденційних блоків відновлюються, пароль зникає.
• Повний експорт/імпорт: 1 продукт, 2 записи архіву за ту саму дату, дати зміни ваги й зросту; дані повернулися після імпорту.

ОБМЕЖЕННЯ
• Справжні Cloudflare Worker/D1, реальні ролі адміністратора, iOS Safari і встановлена PWA не перевірялися (потрібна перевірка в цільовому середовищі).
• Не можна гарантувати абсолютну довговічність localStorage: браузер/користувач можуть видалити дані, спрацює ліміт диска, поламається пристрій або синхронізація зіткнеться з конфліктом. Зберігайте JSON-резервні копії.
• Основні форми (наприклад, «Зберегти профіль», «Зберегти продукт») як і раніше потребують явного збереження; чернетка «Зручностей» не переноситься через JSON-експорт і не синхронізується Cloudflare.
• Задля конфіденційності пароль генератора не зберігається навіть локально, а також очищується після виходу/згортання.

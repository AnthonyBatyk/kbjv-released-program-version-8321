ЗМІНИ
• Шість кнопок «Очистити» у «Зручностях» завжди доступні — навіть без даних.
• Якщо блок порожній, натискання показує червоне «Немає що очищати».
• Якщо є дані, блок очищується і показує зелене «Очищено».
• Як в основних вкладках, підсвічування триває 1450 мс та автоматично зникає.
• Всі кнопки «Зручностей» (включно з кнопками вибору в модальних вікнах) узгоджено з основними кнопками за розміром та жирністю шрифту; очищення має ті самі відступи, радіус, базові кольори та реакцію на наведення.
• Годинник не має кнопки очищення; його часовий пояс зберігається. Паролі не зберігаються.
• Інші розділи, структура даних, імпорт/експорт, авторизація та Worker не змінювались.

ОБМЕЖЕННЯ
Локальні тести у Chromium на ширинах 320, 390, 768 і 1280 px підтвердили червоне повідомлення для порожнього та зелене для заповненого блоку у всіх 6 розділах, повернення кнопок до базового стану та відсутність горизонтального переповнення. Синтаксис трьох JS-файлів перевірений через node --check.

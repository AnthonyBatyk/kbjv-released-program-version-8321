КБЖВ v107 — тестова версія (оновлення v106)

Зміни:
- У всіх шести блоках «Зручностей» кнопки «Копіювати» залишаються доступними навіть без розрахунку/пароля.
- Якщо значення немає, після натискання відображається червоне «Немає що копіювати» (1450 мс).
- Успіх: зелене «Скопійовано»; помилка доступу до буфера: червоне «Не скопійовано».
- Кольори, тривалість анімації і повернення напису відповідають кнопкам «Очистити».
- Немає копіювання порожніх значень, помилкових записів про успіх чи записів самих паролів до консолі.
- Оновлено номер версії сайту та PWA-кешу до v107. Cloudflare Worker v91 не змінено.

Файли, що відрізняються від v106: index.html, utilities.js, script.js, sw.js.
Незмінні: style.css, manifest.webmanifest, іконки.

Обмеження: локальні браузерні перевірки не підтверджують роботу на фізичному iPhone чи з живим Cloudflare D1.

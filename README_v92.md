## Розгортання

1. Зробіть резервну копію поточного тестового репозиторію перед заміною.
2. Завантажте **всі файли із кореня цього архіву**, не створюючи вкладеної папки, до кореня тестового репозиторію GitHub. Зокрема завантажте НОВИЙ файл `utilities.js`.
3. Дочекайтеся публікації GitHub Pages. Відкрийте сайт онлайн, оновіть його, за потреби перезапустіть встановлену PWA.
4. **Cloudflare Worker міняти НЕ потрібно**: використовуйте поточний `kbjv-auth-api-dev` v91 та поточну тестову D1, без змін або міграцій.
5. **Робочий репозиторій, робочий Worker і робочу D1 не змінюйте.**

## Нове в v92

- Під «Консоль:» додано самостійну квадратну кнопку зі стрілкою вправо. Вона НЕ є п’ятою кнопкою панелі вкладок.
- Екран «Зручності» приховує всі чотири вкладки, зберігає верхній рядок профілю та має кнопку «← Назад». Повернення відкриває попередню вкладку та відновлює прокрутку.
- Генератор паролів: довжина 1–128, вибір малих/великих літер, цифр і спецсимволів; захищена браузерна випадковість Web Crypto (`crypto.getRandomValues`); представлений кожен увімкнений клас; кнопка копіювання; приблизна індикація надійності (не перевірка на витік).
- Коефіцієнт штанга/власна вага: десятичні дроби через кому або крапку, десяткова раціональна арифметика, виведення до 10 знаків після коми.
- Конвертер lbs ↔ кг: точне визначення 1 lb = 0,45359237 кг, результат до 8 знаків після коми.
- Інструменти НЕ пишуть у localStorage, sessionStorage, IndexedDB, Cloudflare D1, консоль дій або архів. Вони не змінюють налаштування основних вкладок. Після виходу значення очищуються. Копіювання пароля до буфера здійснюється лише натисканням користувача.
- PWA cache версії `kbjv8321-pwa-v92` із кешуванням нового `utilities.js` та versioned URL ресурсів. Не чіпає кеш основного сайту.

## Контроль якості

- Синтаксис: `node --check` для `script.js`, `utilities.js`, `sw.js`.
- Перевірка DOM / CSS / JavaScript у Chromium для 1280 px, 390 px, 320 px (спеціальний стенд без авторизації): відкриття/повернення, верхній профіль, приховування головної навігації, 11-значний цифровий пароль, копіювання, 170 ÷ 68,5 = 2,4817518248×, 405 lbs = 183,70490985 кг, очищення введення, відсутність нових записів сховища під час роботи з інструментами та відсутність JS-помилок.
- Важливо: перевірка була локальною (стенд без реального входу). Роботу з живою D1/Worker, iPhone Safari/PWA та оновленням кешу після публікації слід перевірити окремо. Інші функції v91 не змінювалися і не проходили повний повторний регресійний цикл.

## Встановлення

1. Зробіть резервну копію тестового репозиторію.
2. Завантажте усі **дев'ять файлів сайту** з архіву до кореня **тестового** репозиторію, замінивши відповідні старі файли. Зокрема, `utilities.js` залишається окремим потрібним файлом.
3. Зробіть Commit, дочекайтеся GitHub Pages і відкрийте тестовий сайт. За потреби перезапустіть PWA, якщо пристрій ще показує v92; `sw.js` використовує новий кеш `kbjv8321-pwa-v93`.
4. Cloudflare Worker, D1, ключі та змінні **не змінювати**. Продакшн-репозиторій та його Worker **не змінювати**.

## Зміни v93 відносно v92

- Стрілка під «Консоль» і «← Назад» використовують нейтральну палітру, ту саму типографіку й вагу шрифту, що й верхня навігація (з урахуванням розміру екрана). Розміщення стрілки не змінено.
- Блоки екрана «Зручності» оформлено як штатні `.tracker`: жодної додаткової постійної рамки або тіні. Поля без постійного контуру; підсвічування з'являється лише у фокусі. Кнопки зберігають штатну анімацію натискання.
- Генерація пароля показує **«Згенеровано» зеленим**, помилка — **«Не згенеровано» червоним**; копіювання аналогічно **«Скопійовано»** / **«Не скопійовано»** з тією ж анімацією стану, що й решта сайту. Через ≈1,45 с початковий текст повертається.
- Підказки для ваги (обидва поля коефіцієнта і поле конвертації) тепер універсальні **«Наприклад: ###»**.
- На початку екрана «Зручності» додано повноширинний годинник **ГГ:ХХ:СС**, дату та вибір часового поясу, включно з Києвом, Варшавою, Парижем, Торонто та іншими. Якщо браузер підтримує `Intl.supportedValuesOf('timeZone')`, доступний повний перелік IANA часових поясів. Літній/зимовий час визначається браузером, а поточний час — годинником пристрою. Оновлення прив'язано до початку секунди для уникнення накопиченого дрейфу.
- Вибір часового поясу та всі інші дані вкладки — тимчасові: нічого не надсилається до Worker/D1, не потрапляє до консолі чи сховища; при поверненні вони скидаються.
- `script.js` оновлено тільки в частині входу на «Зручності» (запуск годинника) і відображуваного номера версії v93. Worker не змінювали. PWA кеш і URL версій оновлено для видачі нових файлів.

## Перевірки

- `node --check` для JavaScript.
- Локальний тест у Chromium на ширинах 1280, 390 і 320 px: стрілка під консоллю, колір/вага тексту, відсутність контурів карток і горизонтального переповнення, вибір часових поясів, зміна секунд, позитивні та негативні стани кнопок, копіювання, очищення даних після повернення, відсутність записів у сховища, без помилок JS.
- Не змінено розрахунок: `170 / 68,5 = 2,4817518248×`; `405 lbs = 183,70490985 кг`.
- НОВИЙ PWA-кеш `kbjv8321-pwa-v93`, версіоновані CSS/JS у HTML/Service Worker. Перевірити реальне оновлення PWA після деплою: локальна середа не дозволила браузеру відкрити HTTP-сервер. Реальний iPhone Safari, авторизація з Worker та D1 не перевірялися на пристрої.

В архіві є `README_v93.md` як довідка, він не потрібен для роботи сайту і його необов'язково завантажувати до GitHub.

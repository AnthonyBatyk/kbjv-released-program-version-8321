# КБЖВ v96 — тестова версія для GitHub Pages

Репозиторій: kbjv-released-program-version-8321.
Ця версія заснована безпосередньо на архіві v95. Робочу версію сайту не змінено.

## Зміни порівняно з v95

1. Виправлено індикатор «Версія сайту»: тепер v96. Значення задається SITE_VERSION у script.js; у HTML початкове значення теж v96. Версія Cloudflare Worker читається окремо з відповіді GET /health, без жорстко заданого номера; Worker та D1 не змінені.
2. На головній сторінці збережено чотири наявні вкладки та окрему квадратну стрілку праворуч під навігацією.
3. На другій сторінці панель містить лише дві вкладки однакової ширини: «Зручності:» та «Консоль:». Синім виділена виключно поточна активна вкладка.
4. Стрілка повернення має той самий SVG, товщину штриха та розміри, що й стрілка переходу, але спрямована вліво й розміщена окремо зліва під другою панеллю. Тексту «Назад» немає.
5. «Консоль:» працює як звичайна вкладка. Повторне натискання не перемикає назад; для переходу до інструментів потрібно натиснути «Зручності:».
6. Два входи в консоль показують ОДИН і той самий DOM #console, ті самі дані журналу, статус сервера, синхронізацію та кнопки; дублювання баз даних немає.
7. Скопійовані коефіцієнти та значення конвертації журналюються, а текст згенерованих/скопійованих паролів — ні. Інші функції v95 збережено.
8. Піднято PWA cache name до kbjv8321-pwa-v96 і параметри версії статичних файлів до ?v=96-8321.

## Оновлення v95 → v96

Замінити в тестовому репозиторії п'ять файлів:
- index.html
- style.css
- script.js
- utilities.js
- sw.js

Іконки та manifest.webmanifest ідентичні до v95. Cloudflare Worker, D1, змінні, секрети та налаштування не змінювати.

## Перевірки

- JavaScript: перевірка синтаксису Node.js для script.js, utilities.js і sw.js.
- UI: Chromium з локально вбудованими HTML/CSS/JS (ізольований тестовий localStorage, без реальних Cloudflare-запитів) на 320 / 390 / 768 / 1280 px.
- Перевірено видимість окремих панелей, 2 колонки, стани активних кнопок після анімації, повторні натискання, повернення до потрібної основної вкладки, відсутність горизонтального прокручування.
- Перевірено відображення v96 в обох входах у консоль, спільні дані журналу, копіювання числових значень, відсутність паролів у журналі, очищення введених значень при виході.
- Живі запити до Worker та поведінку на фізичному iPhone потрібно перевірити після публікації.

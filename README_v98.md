# КБЖВ v98 — тестовий реліз для GitHub Pages

Репозиторій: `kbjv-released-program-version-8321`.
Базова версія: v97. Робочу версію та Cloudflare Worker v91 не змінено.

## Зміни

1. **Профіль** — код не змінювався. Підтверджено, що `weight_updated_at` і `height_updated_at` входять до повного та профільного JSON-експорту й відновлюються при імпорті. У локальному тесті обидві дати витримали повний цикл «експорт → імпорт».
2. **Архів, середні за 7/14/30 днів** — замість `ккал` показується «калорій», а для інших метрик текстові позначення: `(білки)`, `(жири)`, `(вуглеводи)`, `(цукри)`, `(сіль)`, `(клітковина)`. Це лише формат відображення: числові поля архіву, одиниці збережених даних (ккал, грами) та формули середніх не змінено.
3. **Коментар архіву** — змінено заголовок на «Тип дня:», прибрано підпис «(необов’язково)». Три позначки «Відпочинок», «Тренування», «Чітміл» розміщено горизонтально; взаємовиключність і можливість не вибирати нічого залишено.
4. **Конвертер** — назва «Конвертер» замість «Конвертер фунтів і кілограмів». Додано 20 категорій / 136 одиниць, автоматичний перерахунок між будь-якими двома одиницями однієї категорії (1130 пар з урахуванням тотожних). Є 24 популярні напрямки на початку (перші два — `lbs→кг` і `кг→lbs`), поле пошуку одиниць, вибір категорії й одиниць «з» та «в», копіювання лише числового результату. Дані/налаштування конвертера не зберігаються.
5. **Точність і межі** — використовуються дроби BigInt, а не арифметика звичайних JavaScript float; від'ємні числа дозволені лише для температур, значення нижче 0 K відхиляються. Де коефіцієнти наближені (наприклад, кут у радіанах через π), це позначено. Цифрові дані чітко відділяють десяткові MB (1 000 000 B) і двійкові MiB (1 048 576 B).
6. **Консоль** — лише успішне копіювання результату конвертації записується в наявний журнал із числом та позначенням одиниці; вміст пароля не журналюється. Зв'язок з Worker та D1 не змінено.
7. **Версії** — номер сайту та кешу PWA = **v98**; Worker залишається **v91** (у разі доступності сервера його версія береться з API).

## Розгортання v97 → v98

У тестовому GitHub-репозиторії замініть тільки **5 файлів**:

- `index.html`
- `style.css`
- `script.js`
- `utilities.js`
- `sw.js`

Інші файли (`manifest.webmanifest`, іконки) не змінилися. Нічого не оновлюйте у Cloudflare Worker, D1, змінних середовища або робочій версії сайту. До оновлення рекомендується виконати повний експорт JSON з поточного сайту.

## Локальні перевірки

- `node --check`: `script.js`, `utilities.js`, `sw.js` — без синтаксичних помилок.
- HTML: дубльованих ідентифікаторів немає.
- Chromium 320/390/768/1280 px: популярні напрямки, пошук, 18 еталонних прикладів, 1130 можливих внутрішньокатегорійних пар у кожному перегляді, копіювання, повернення до початкового стану, горизонтальна розкладка трьох типів дня.
- Інтеграційний Chromium з тестовою авторизацією і підставленим API: статистика на 40 записах, перемикання показників, коментарі, профіль, повний JSON експорт, імпорт і збереження обох дат зміни ваги/зросту, запис копіювання в консоль. Тести пройшли без винятків JavaScript.
- Реальні Cloudflare D1, обліковий запис користувача й фізичний iPhone в цьому локальному тесті **не використовувалися**.

**Важливо:** «усі одиниці вимірювання» буквально не можна охопити скінченним переліком; v98 містить широку добірку найбільш застосовних фізичних і цифрових одиниць. Калорії в середніх — користувацький напис, але дані всередині, як і раніше, в кілокалоріях.

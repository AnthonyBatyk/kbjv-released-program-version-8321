# КБЖВ — тестова версія v99

Це повний набір файлів GitHub Pages для тестового репозиторію `kbjv-released-program-version-8321`. Основну робочу версію сайту не змінено. Cloudflare Worker / D1 не потрібно змінювати; поточний Worker v91 зберігається.

## Архів

- Картки «Середнє значення» за 7, 14 і 30 днів тепер відображають «калорій», «білків», «жирів», «вуглеводів», «цукрів», «солі», «клітковини» без дужок, залежно від обраної метрики.
- У вікні коментаря прибрано зайвий порожній відступ між полем і «Тип дня». Три позначки залишилися горизонтальними та взаємовиключними.
- У відображенні позначки залишено тільки «✓ Відпочинок», «✓ Тренування», «✓ Чітміл» без слів «був/було».

## Зручності

- Заголовки «Поточний час:», «Генератор паролів:», «Коефіцієнт піднятої ваги:» та «Конвертер:» з двокрапками.
- Конвертер спрощено: у головній частині тільки вибір напрямку, число та результат. Повний каталог 20 категорій / 136 одиниць з пошуком не видалено: відкривається в «Усі одиниці — вибрати вручну». Початковий напрям — фунти → кг.
- Додано «Порівняння цін товарів:». Два варіанти, ціна в грн, кількість, одиниці (маса, об'єм, штуки, довжина, площа) і спільна база порівняння. Показує ціну кожного варіанта за ту саму кількість та вигідніший варіант; можна скопіювати результат. Використано раціональну десяткову арифметику BigInt. Ціни мають бути в одній валюті.
- Додано «Калькулятор дат:»: дві дати й необов'язковий час з точністю до секунди, календарний розклад (роки, місяці, дні, години, хвилини, секунди) та повна кількість діб/годин/хвилин/секунд, копіювання результату. Для відсутнього часу використовується 00:00:00. Доби трактуються як рівно 24 години, без літнього/зимового часу; порядок дат неважливий.
- Нові інструменти **нічого не зберігають** у базі даних і LocalStorage. У консолі фіксується факт успішного копіювання, без значень цін та дат. Дані очищуються після виходу зі «Зручностей». Наявний журнал, профіль, калькулятор та системні налаштування не змінені.

## Як оновити

Для переходу **v98 → v99** замінити в тестовому GitHub-репозиторії:

1. `index.html`
2. `style.css`
3. `script.js`
4. `utilities.js`
5. `sw.js`

`manifest.webmanifest`, `icon.png`, `icon-192.png`, `icon-512.png` залишаються без змін. Після публікації дочекатися оновлення PWA-кешу до v99. Cloudflare Worker v91 і D1 не змінювати.

## Перевірки

- `node --check` для `script.js` і `utilities.js`.
- Локальні Chromium-тести нових інструментів і розмітки на 320, 390, 768 та 1280 px без горизонтального переповнення або JavaScript-помилок. Браузерні тести виконано на ізольованому DOM без реального входу через Cloudflare.
- Перевірено 700 грн за 1 кг проти 200 грн за 100 г: 70 грн проти 200 грн за 100 г, вигідніший перший варіант на 65%.
- Перевірено 200 грн за 30 шт. проти 50 грн за 5 шт.: близько 6,67 грн/шт. проти 10 грн/шт.
- Перевірено високосний рік, дати у зворотному порядку, точність до секунди й очищення значень.
- В архіві CSS-відступ між textarea та легендою позначок дня в ізольованому Chromium становить 7 px на екрані 390 px.

**Потрібна фінальна перевірка на реальному iPhone й опублікованій тестовій версії із Cloudflare.**
